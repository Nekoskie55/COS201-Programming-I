## Week 3: Variables, Data Types, Expressions and Input/Output

### Objectives
- Declare and initialize Java variables.
- Use appropriate primitive and reference data types.
- Perform arithmetic calculations.
- Read keyboard input using Scanner.
- Display formatted output.

### Programs
1. `week03/SimpleCalculator.java` - arithmetic on two numbers (with zero-divisor check).
2. `week03/AverageCalculator.java` - total and average of three scores (with 0-100 validation).
3. `week03/ItemCost.java` - total cost from quantity and unit price.

### How to Run
Open a terminal in the `week03` directory, then for each program:
- `javac SimpleCalculator.java` then `java SimpleCalculator`
- `javac AverageCalculator.java` then `java AverageCalculator`
- `javac ItemCost.java` then `java ItemCost`

### Testing
Each program was tested with several valid inputs and edge cases (zero divisor, scores outside 0-100) and the results matched the expected calculations.
